# Galería local de profesionales

Guarda aquí las fotos autorizadas de trabajos realizados, organizadas por el identificador estable del profesional:

```text
storage/gallery/<professional-id>/<image-name>.<extension>
```

El XML de `runtime/data/professionals.xml` conserva rutas relativas a esta carpeta, no el contenido binario de las imágenes. Antes de adjuntar una foto por WhatsApp, verifica que el archivo exista, corresponda al perfil y tenga autorización para compartirse. No sustituyas el adjunto por enlaces externos.

No agregues imágenes reales ni datos personales a repositorios públicos. Los comprobantes de comisión no pertenecen a esta galería: se conservan en `storage/evidence/commission-payments/` con acceso restringido.
