# Documentación del proyecto

- `business/system-specification.md` es la fuente de verdad funcional.
- `operations/whatsapp-bot.md` explica configuración, ejecución y límites del webhook.

Mantén `config/business/business-rules.yaml`, el contexto conversacional, las skills y la implementación alineados con la especificación funcional.

Las skills son procedimientos y restricciones, no prueba de que una capacidad esté implementada. `skills/README.md` contiene el índice y las reglas transversales para precedencia, fallos, privacidad y escalamiento.
