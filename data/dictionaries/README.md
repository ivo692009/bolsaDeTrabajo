# Diccionarios locales

Contienen definiciones compactas y ampliables para orientar consultas por oficio. La fuente inicial se limita a información general del proyecto y al catálogo local; no certifica matrícula, habilitación, experiencia, seguridad ni disponibilidad de una persona.

- `professional-activities.yaml`: descripción de oficios, actividades comunes, ejemplos de solicitud y límites de orientación.

Las skills `professional-activity-dictionary-lookup.md`, `professional-activity-dictionary-maintenance.md` y `professional-registration-activity-enrichment.md` indican cómo consultar, ampliar y respaldar estas definiciones. Para ahorrar tokens, recuperar solo el oficio y las actividades pertinentes; no adjuntar el diccionario entero a una consulta.

Las profesiones afines son sugerencias para distinguir tareas o pedir una aclaración, no equivalencias automáticas. Solo las categorías y trabajos del catálogo XML pueden asignarse a un perfil o usarse para filtrar profesionales. Las referencias extranjeras ayudan a describir tareas generales; no fijan requisitos argentinos.
